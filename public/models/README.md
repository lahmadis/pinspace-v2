# 3D Models (GLB)

Place `.glb` (or `.gltf`) model files in this folder to view them in the app.

**How to use:**

1. Add your GLB file here (e.g. `my-model.glb`).
2. Open **3D Model** from a studio page, or go to `/model`.
3. Enter the path `/models/my-model.glb` and click **Load**, or open directly: `/model?url=/models/my-model.glb`.

Files in `public/` are served from the site root, so `public/models/example.glb` is available at `/models/example.glb`.
